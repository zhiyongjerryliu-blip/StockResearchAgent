# 美股投研工作台

个人自用的本地美股投研、持仓收益与每日复盘软件。当前稳定版本为 **v1.0**，已形成从数据采集、基本面与资金行为分析、多周期预测验证、投资建议到无人值守日终复盘的完整闭环。

## 当前已实现

- 本地单用户 Web 界面；
- 桌面主题支持浅色、深色和跟随 macOS 系统，并在本机浏览器保存选择；
- SQLite 数据库，无需安装数据库服务；
- 股票池添加、修改、删除、暂停和恢复；
- 按日期录入买入、加仓、部分卖出及清仓交易流水；
- Excel/CSV 交易文件预检、批量导入、重复文件防重和未知股票自动入池；
- FIFO 批次和移动平均成本；
- 已实现、未实现、今日及累计盈亏；
- 免费优先的 Yahoo 日行情 Provider；
- 手动收盘价补录；
- 每日持仓快照；
- 综合可靠度评分和 85 分发布闸门；
- 应用内、macOS 桌面和 SMTP 邮件通知框架；
- OpenAI-compatible 云端 LLM 接口；
- 收盘后单股和股票池基础复盘；
- 定时行情更新和日终任务；
- 独立系统状态页，展示服务运行时间、富途心跳、数据库容量、备份和股票池数据完整度；
- 每日运行中心按步骤记录SEC、行情、宏观、预期、新闻、资金、预测、建议、复盘和组合风险的状态、耗时、处理数量、失败原因及重试次数；
- 日终网络步骤支持有限自动重试，局部失败会明确降级但继续完成可执行步骤；最终统一检查行情口径、数据新鲜度和预测/建议/复盘输出完整性；
- 支持从运行中心按美股交易日和单只股票幂等重跑；同一进程禁止并发执行两条日终流水线，持续失败以应用内、macOS和邮件渠道幂等提醒；
- 每日SQLite完整性检查、WAL检查点、过期逐笔清理和本地数据库备份，默认保留最近7份；
- 富途采集器心跳超时检测和指数退避自动重连；
- 富途采集异常时自动拉起本机OpenD，设置冷却时间防止频繁启动；连续失败和恢复均生成本地通知；
- 自动日终严格按美股交易日历运行；Mac休眠、退出登录或服务中断错过任务后，启动及运行中会顺序补跑遗漏交易日；
- 自动日终使用SQLite持久化任务租约，同一交易日不会因服务重启或并发进程重复执行，失败任务按冷却时间有限重试；

- 新闻风险规则初筛与原文追溯；新闻事件始终标记为待核实、不会生成P0，P1提醒要求一线媒体或多家独立来源佐证；

- 盘中不混用未完成日线，宏观指标统一回退到最近已稳定的美股交易日；
- 1/3/6个月证据加权影响评分和条件式投资建议，逐项展示价格、事件、宏观、估值、EPS修订及基本面贡献；

- 组合风险中心计算单股与行业集中度、约90日持仓相关性和年化波动率，以及基于每日持仓快照的已记录最大回撤；
- 持仓复核建议结合组合权重、累计收益、最新结构化建议和SEC官方风险，输出集中度减仓或风险退出复核，但不提供自动仓位比例且不执行交易；

## 连续资金行为与验证

“资金与成交量”页面会把单日资金信号进一步组合为连续阶段，包括加速吸筹、持续吸筹、下跌承接、中性、上涨派发、持续派发和加速派发。富途逐笔可用时，模型合并主动成交差和VWAP位置；缺少历史逐笔时明确降级为日线量价代理，不会把公开成交误写成已确认的机构持仓变化。

系统按信号后的第1、3、5、10、20个交易日结算方向命中、最大有利变动（MFE）和最大不利变动（MAE），并在页面逐条展示已到期和待验证样本。看多阶段收益大于+1%才算方向命中，看空阶段收益小于-1%才算命中；可靠度只使用互不重叠的已到期样本，最低样本数和85分门槛任一未满足时均保持观察状态，不进入正式投资建议。

当同一有方向阶段连续两个交易日出现、且此前阶段不同，系统生成一次阶段切换提醒并用事件键防止重复。加速派发只有在20日验证状态为`PUBLISHED`且可靠度不低于85分时才升级为P1，其余均为P2研究提醒。投资建议采用相同门槛：验证通过后，连续阶段与当日日线资金分按45%/55%合并；验证未通过时只展示阶段与可靠度，不改变建议分数。

接口：`GET /api/capital-behavior?ticker=LITE`查看当前阶段、20日历史和累计验证；`POST /api/capital-behavior/backtest`传入股票代码生成历史阶段与前向验证账本。日终任务会自动更新股票池中的连续资金行为验证。

## 预测中心与历史验证

“预测中心”会为所选股票按历史交易日生成时点特征，并用冻结的V1可解释模型分别计算21、63和126个交易日预测。历史样本使用其后对应交易日收盘价结算；尚未走完预测期限的样本只标记为待到期，缺少基准日完整日线或历史不足的样本会被排除。

系统同时保存全部逐日回测结果和按期限抽取的非重叠有效样本。综合可靠度仅使用非重叠样本，避免连续交易日预测高度重叠造成虚假样本量。1、3、6个月最低有效样本分别为60、32和16个；即使综合分超过85，样本不足时仍保持`INSUFFICIENT`，不会发布正式预测。

当同一股票至少存在两个交易日的预测时，系统会将最新预测与上一次相同期限、相同模型版本的预测比较。预期收益变化拆分为动量、相对强弱、资金行为、估值、EPS预期、基本面、宏观和事件八类模型贡献；目标中位价变化则精确拆分为市场价格效应和收益预期效应。该归因描述的是冻结模型内部的数学变化，不代表已经证明新闻或宏观事件与股价之间存在因果关系。

“同一目标日的跨期限演变”以最新1个月或3个月预测的目标日为锚点，向前匹配指向同一终点的更长期预测，形成6个月、3个月、1个月的观点演变时间线。为容纳美股节假日造成的估算偏差，目标日允许最多相差7个自然日；系统比较目标中位价和预测区间，不直接比较起点不同的收益率。

V1用于建立可审计的数据、预测和验证账本，不代表模型已经训练完成。后续模型训练只能读取相应历史基准日之前可获得的数据；LLM只负责解释结构化预测和差异原因，不参与修改预测数值。

接口：`GET /api/predictions?ticker=LITE`查看最新预测和累计验证；`POST /api/predictions/backtest`传入股票代码运行历史特征生成与回测。日终任务会在投资建议之前自动更新股票池预测，使建议继续受可靠度闸门约束。

## 停止和重启

```bash
npm stop
npm restart
npm run service:status
```

服务启动成功后会在 `data/server.pid` 记录进程号。`npm stop` 通过当前用户的 LaunchAgent 精确停止本项目，不会按名称批量终止其他 Node 程序。运行日志分别保存在 `data/logs/server.log` 和 `data/logs/server-error.log`，单个日志超过 10MB 后会在下一次启动或重启时轮换，保留最近 3 份。

“系统状态”页面会每30秒刷新运行信息。自动维护每天至少执行一次，包括数据库完整性检查、WAL检查点、过期逐笔清理和一致性备份；也可以点击“立即检查并备份”手动执行。备份位于 `data/backups/`，不会包含 `.env` 中的密钥。

维护参数可在 `.env` 中调整：

```dotenv
DATABASE_BACKUP_RETENTION_COUNT=7
DATABASE_WARNING_MB=512
SYSTEM_MAINTENANCE_CHECK_MINUTES=60
FUTU_HEALTH_CHECK_SECONDS=30
FUTU_HEARTBEAT_TIMEOUT_SECONDS=120
FUTU_RECONNECT_MAX_SECONDS=300
FUTU_AUTO_LAUNCH_OPEND=true
FUTU_OPEND_LAUNCH_COOLDOWN_SECONDS=300
DAILY_CYCLE_RETRY_ATTEMPTS=2
DAILY_CYCLE_RETRY_DELAY_MS=1000
DAILY_CYCLE_CATCHUP_LIMIT=5
DAILY_CYCLE_AUTOMATION_MAX_ATTEMPTS=3
DAILY_CYCLE_AUTOMATION_RETRY_MINUTES=15
DAILY_CYCLE_CLAIM_STALE_MINUTES=30
```

自动日终不再依赖“恰好在18:15 ET保持唤醒”。调度器每分钟计算最近一个已稳定收盘的美股交易日，并与SQLite中的完成记录核对；发现遗漏后自动补跑。休市日不会创建新的交易日任务，进程崩溃留下的超时租约会在冷却后由新进程接管。日终流水线在独立工作线程运行；默认单次最多顺序补跑5个交易日、整个任务最多自动尝试3次，单次超过60分钟将终止并进入安全重试。

## 每日运行中心

“系统状态”页面中的“每日运行中心”展示最近一次日终流水线的逐步状态和数据质量结果。网络采集步骤默认最多执行2次；某一Provider局部失败时任务标记为`DEGRADED`并继续使用数据库中最后一份可用数据，所有降级项都会在最后的数据质量验收中再次列出。行情检查会核对预期交易日、OHLC/成交量字段，并在同日不同Provider收盘价相差超过0.1%时标记为口径异常。

可以选择一个已经完成的美股交易日和单只股票重新执行，或者选择“全部股票”重跑完整流水线。历史重跑不会读取指定日期之后的预测特征和建议输入；持仓快照和组合风险仍会整体重算，以保持组合口径一致。接口为`GET /api/operations/daily`、`GET /api/operations/daily/:id`和`POST /api/operations/daily/rerun`。

如需彻底移除 LaunchAgent，但保留数据库和日志：

```bash
npm run service:uninstall
```

如果启动时提示端口 `3789` 已被其他程序占用，先运行 `npm stop`。如果仍然占用，可以在 `.env` 中修改：

```dotenv
APP_PORT=3790
```

## 批量录入交易

打开“交易流水”，在右侧“批量录入交易”区域下载 Excel 模板。系统也接受同样表头的 CSV 文件，单个文件最大 5 MB、最多 1000 笔交易。

模板列依次为：`交易日期`、`股票代码`、`股票名称`、`交易方向`、`股数`、`成交价`、`交易费用`、`备注`。交易日期使用 `YYYY-MM-DD`；方向填写 `BUY`/`SELL` 或“买入”/“卖出”；股数必须大于 0；成交价和交易费用不能为负，其中费用留空按 0 处理。

上传后软件只做预检，不会立即写入。预检会检查表头、日期、数值、重复行和历史持仓是否足够卖出。全部通过并点击“确认批量导入”后才会原子写入；文件内未在股票池中的代码会同时新增到股票池。已经成功导入过的相同文件不能重复导入。

## 云端 LLM

复制 `.env.example` 为 `.env` 后配置：

```dotenv
LLM_ENABLED=true

LLM_API_KEY=你的密钥
LLM_MODEL=你选择的模型名称
```

## SEC EDGAR 联系信息

SEC 要求自动访问者通过 HTTP `User-Agent` 标识身份并提供真实联系邮箱。在项目根目录的 `.env` 中配置：

```dotenv
SEC_USER_AGENT=你的姓名 your-email@example.com
SEC_REQUESTS_PER_SECOND=5
```

例如：

```dotenv
SEC_USER_AGENT=Zhang San zhangsan@example.com
```

`SEC_USER_AGENT` 不是 SEC 账户或 API Key，只是请求身份标识。软件界面只显示是否已配置，不会回显姓名和邮箱。SEC Provider 会拒绝缺少有效联系邮箱的自动请求，并将请求速率限制在每秒 1–10 次范围内。

配置完成并重启软件后：

1. 将股票加入股票池；
2. 打开“财报分析”；
3. 选择股票并点击“同步 SEC 数据”；
4. 查看最新核心指标、年度/季度趋势以及 10-K、10-Q、8-K 原文。

当前标准化范围以 `us-gaap` 核心概念为主，包括营业收入、毛利润、营业利润、净利润、摊薄 EPS、经营现金流、资本开支、总资产、总负债、股东权益、现金及摊薄加权股数。公司自定义 XBRL 扩展标签和 IFRS 指标将在后续版本补充。

## Alpha Vantage 盈利预期

在项目根目录的 `.env` 中配置免费 Alpha Vantage Key：

```dotenv
ALPHA_VANTAGE_API_KEY=你的Key
```

日终任务会为股票池标的及两家自动对标公司同步分析师一致预期，同一股票同一交易日只请求一次，避免浪费免费额度。动态 PE 优先使用未来四个连续财季平均 EPS 之和；若 Provider 只给出不足四个未来财季，则按距离最近财年末的天数滚动加权未来两个财年的平均 EPS；若下一财年几乎完整覆盖未来十二个月，则允许以该财年预期近似 NTM，并明确标记为近似值。系统保存基准日、上下限、最低分析师覆盖数、预期修订和逐期组成，且不会在数据不足时发布动态 PE。

同一个 Key 也用于 Alpha Vantage `NEWS_SENTIMENT`。系统同时采集 Google News RSS、Yahoo Finance 新闻和 Hacker News 公开讨论；前三者覆盖财经及广泛媒体，Hacker News 补充科技社区讨论。各来源独立执行，单一来源失败不会阻断其余来源，逐源诊断会保存在本次同步结果中。

日终任务按股票池逐只保存来源、发布时间、相关性、股票级情绪、讨论热度和原文链接，并按规范化URL与标题指纹合并跨渠道重复内容。页面展示近7日新闻/讨论数量、独立来源数、平均情绪、负面占比、讨论热度和24小时声量变化；少于3条或不足2个独立来源时不会输出多空趋势。首次多来源同步只回填历史且不补发提醒；后续高相关P1信号只有来自一线媒体，或同一事项得到至少两个独立媒体来源佐证时才触发通知。社区讨论单独出现时最高只标记P2。所有新闻和舆情判断都是待核实线索，不等同于事实确认，也不会产生P0事件。

Google News RSS 的使用仅限本软件的个人、非商业研究场景；Alpha Vantage 免费套餐有调用额度，股票池较大时应关注日终任务中的逐股、逐源错误记录。Reddit 官方目前要求登记应用并使用 OAuth；Stocktwits 暂停新 API 注册，因此本版本不会通过未认证抓取绕过平台要求。

## 个股外部驱动

在“事件与风险”中选择股票后，页面会展示公司动作、行业/产业链信息和宏观利率三类驱动。公司动作优先使用SEC Company Facts中的普通股回购现金支出与资本开支；新闻规则补充回购授权、实际回购、产能扩张或收缩、重大投资、供应协议和行业价格/供需事件。所有新闻驱动均标记为待核实，不自动建立股价因果。

个股概念用于扩展Google News行业检索。LITE和SNDK包含专用概念规则；其他股票在存在用户填写行业或SEC行业信息时生成通用行业查询。行业龙头、云厂商、竞争者和上下游公司默认只作需求或产业链代理；只有公开文件明确披露关系时才显示“已核实关系”。

宏观代理来自Yahoo免费日行情：`^TNX`、`^IRX`、`ZN=F`、`ZQ=F`和`TLT`。`ZQ=F`按“100−期货价格”换算隐含月均有效联邦基金利率，仅用于观察预期变化，不是CME FedWatch概率。Yahoo代理值也不是美国财政部的官方成交价。日终和手动同步只使用美东18:15后稳定的最近交易日，盘中不会把当日未完成期货线与前一日收益率混合判断。

## 影响评分与投资建议

系统不会把单条外围新闻直接翻译成买卖指令。每条事件先按来源可信度、与公司的关系类型、严重度、方向和时间衰减形成事件分，再和价格趋势、资金行为、利率环境、当前估值、EPS一致预期修订及营收/毛利表现共同合成 `-100` 到 `+100` 的影响分。资金行为对1个月建议权重为20%，3个月为12%，6个月为7%；3个月提高估值及EPS修订权重，6个月进一步提高估值与基本面权重。

建议分为“候选买入、候选加仓、持有、候选减仓、谨慎持有/评估减仓、风险退出评估、观察、暂不买入”。其中正式候选买入、加仓和减仓必须同时存在对应期限的 `PUBLISHED` 预测、综合可靠度不低于85分、预测方向与影响分一致且证据置信度达到最低要求。未通过闸门时只能输出观察、持有复核或风险复核，不发布目标位；未经核实的新闻不能单独生成正式清仓指令。SEC官方P0/P1事件可以触发风险优先评估，但仍要求用户核实事实和价格反应。

建议快照按“股票、日期、期限、模型版本”幂等保存，用于后续逐日比较和历史验证。所有取数均限制在建议日当时已经可获得的数据，避免使用未来行情、后来发布的财报或后来更新的一致预期。由于当前尚未配置个人风险承受度、流动性需求、最大单股仓位和最大可接受回撤，系统暂不输出具体仓位百分比。

## 资金行为识别

独立的“资金与成交量”页面提供日线资金行为识别和每日成交量趋势，不与“事件与风险”的筛选条件共用股票选择器。第一版使用最近公开日线OHLCV计算20日方向性成交额代理、CMF、MFI、涨跌成交量差、OBV方向代理、当日收盘位置、相对成交量及量价背离，输出 `-100` 到 `+100` 的行为评分，并分为强建仓、温和建仓、中性、温和派发、强清仓和数据不足六类。

系统同时逐日保存原始成交量、5日均量、前20日均量、最新量比以及5日相对20日的成交量趋势。当最新成交量达到前20日均量的1.5倍，并且当日涨幅达到2%时生成P2“明显放量上涨”提醒；达到相同量比且跌幅达到2%时生成P1“明显放量下跌”风险提醒。同一股票、交易日和异常类型只提醒一次。提醒进入应用内通知，并按本地配置继续发送macOS桌面通知和邮件。

该模块不会把成交量直接冒充为真实机构净流入，也不会显示无法由日线验证的“主力净流入金额”。公开行情没有最终交易账户身份，当前结果统一标记为 `DAILY_PROXY`，证据置信度最高限制为72分。后续接入全市场逐笔成交与报价、FINRA场外成交/短卖数据和SEC 13F后，才会升级数据等级并重新校准评分。

资金行为快照按“股票、分析日期、模型版本”幂等保存，日终任务自动生成。手动点击“识别资金行为”也可立即更新所选股票；查看接口为 `GET /api/capital-flow?ticker=LITE`，保存接口为 `POST /api/capital-flow/run`，历史快照接口为 `GET /api/capital-flow/history?ticker=LITE`。所有计算只读取分析日期当日及之前的行情，防止未来数据泄漏。

### 富途分钟行情与主动成交方向

安装并登录 Futu OpenD 后，可用富途只读行情补充1分钟K线和逐笔成交方向。首次使用在项目根目录运行：

```bash
npm run setup:futu
npm restart
```

默认连接 `127.0.0.1:11111`，只订阅股票池中启用标的的美股常规交易时段行情，不创建交易连接，也不会下单。连接参数可通过 `.env` 中的 `FUTU_ENABLED`、`FUTU_OPEND_HOST`、`FUTU_OPEND_PORT`、`FUTU_PYTHON_PATH`、`FUTU_MARKET_SESSION` 和 `FUTU_BACKFILL_DAYS` 修改。

首次接入某只股票且本地不足一个完整交易日的分钟线时才申请历史回补；正常重启会复用已入库分钟线，不重复消耗历史行情额度。实时订阅仍会用富途缓存补齐最近1000根分钟线和1000笔成交。逐笔事件默认缓存2秒后批量提交，同一批次内的分钟统计先在内存聚合再写库；资金流快照默认30秒一次，避免逐笔高峰造成大量SQLite事务。原始逐笔默认保留7天用于审计。可用 `FUTU_INGEST_BATCH_MILLISECONDS`、`FUTU_SNAPSHOT_INTERVAL_SECONDS` 和 `FUTU_TICK_RETENTION_DAYS` 调整，允许范围分别为250–10000毫秒、5–300秒和1–30天。

“资金与成交量”页的“分钟资金流向”按富途逐笔 `BUY/SELL` 方向统计主动买入成交额、主动卖出成交额、净主动成交额、大额成交方向、VWAP位置和最近10分钟明细，并保存分钟快照。历史1分钟K线可以在富途额度允许时回补，但采集器启动前的历史逐笔方向通常不能完整回补，因此页面会区分完整逐笔、部分逐笔和分钟量价代理数据等级；逐笔分钟覆盖不足时会压低评分和置信度。

分钟资金流已进入投研闭环：交易日匹配、完整逐笔且置信度达到55分后，才作为独立因子进入1、3、6个月条件式建议，期限越长权重越低；显著主动卖出即使达到高置信，也只能单独触发“谨慎持有/评估减仓”，不能据此生成清仓结论。置信度达到60分的P1主动买入或主动卖出失衡会立即生成应用内、macOS及已配置邮件提醒，并按股票、交易日和异常类型去重。收盘复盘会同时保存日线量价资金行为和分钟逐笔方向，便于后续验证两类信号与实际价格的关系。

最近10个交易日表格会把已采集的富途逐笔方向汇总为主动流入、主动流出和净主动成交额：流入按正值红色显示，流出按负值绿色显示。下方组合图保留成交量、5日均量和20日均量折线，并用右侧美元轴叠加净流向柱体（红色向上表示净流入，绿色向下表示净流出）。未采集到历史逐笔方向的交易日显示为空，不使用日线量价代理伪造资金流金额。

这里的主动成交方向只表示成交更接近当时卖盘或买盘，不能识别最终账户，也不能据此宣称某家机构或“主力”正在买卖。该信号应与日线量价、价格趋势、财报、估值和事件证据共同使用。

## 估值与竞争对手

打开“估值与同业”后，系统会根据股票代码、SEC SIC 行业和股票池行业信息，自动选取两家同行业上市龙头作为对标公司，不需要手工维护竞争对手。对标公司只作为研究标的保存，不会加入持仓股票池；点击“自动匹配并同步同业”会同时获取目标公司和两家对标公司的免费 Yahoo 日行情及 SEC 财务数据。页面会显示匹配方式、规则版本和可追溯的行业依据；无法可靠识别行业时会明确提示，不会随意猜测。

静态 PE 使用“最新收盘价 ÷ TTM GAAP 摊薄 EPS”。最新财年结束后直接使用 SEC 最新年度 EPS；财年后已有 10-Q 时，使用“最新年度 EPS + 本期 YTD EPS − 上年同期 YTD EPS”滚动到最近十二个月；只有缺少年度数据时才回退到四个连续季度之和。缺少可比期间或 TTM EPS 不为正时，系统明确显示原因且不发布无意义数值。

动态 PE 使用“最新收盘价 ÷ NTM 预期 EPS”。系统自动同步 Alpha Vantage 分析师一致预期并保留每日历史快照；手工录入仅作为 Provider 无覆盖或需要人工覆盖时的备用口径。Alpha Vantage 预期与 SEC GAAP 历史 EPS 可能采用不同调整口径，页面会保留来源和计算方法，不能把静态 PE 与动态 PE 的差异全部解释为盈利增长。

同业中位数只使用两家自动对标公司中的有效值，不包含目标公司；页面同时展示年度营收同比和毛利率，缺失或无意义的数据不会进入中位数计算。

## 日终任务

默认按美东时间 18:15 检查并执行日终任务，包含：

1. 更新启用股票行情；
2. 同步启用股票的 SEC 申报与核心财务事实；
3. 同步 Alpha Vantage 盈利预期和每日新闻；
4. 同步美债、国债期货及联邦基金期货代理并判断利率环境；
5. 识别并保存每只股票的成交量趋势和资金行为，对明显放量上涨/下跌发送幂等提醒；
6. 计算并保存每日持仓收益；
7. 生成纳入资金行为、公司动作、产业链和宏观环境的单股复盘；
8. 生成股票池总复盘；
9. 发送完成通知。

如果 `SEC_USER_AGENT` 尚未配置，日终任务会跳过 SEC 同步而不会阻断行情、收益和复盘流程。单只股票同步失败也只记录该股票错误，不会终止整个股票池任务。

也可以在界面点击“执行日终任务”手动运行。
