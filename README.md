# 美股投研工作台

个人自用的本地美股投研、持仓收益与每日复盘软件。当前版本已进入第二阶段基本面研究，重点建立可信的数据、交易、估值和历史版本底座。

## 当前已实现

- 本地单用户 Web 界面；
- SQLite 数据库，无需安装数据库服务；
- 股票池添加、修改、删除、暂停和恢复；
- 按日期录入买入、加仓、部分卖出及清仓交易流水；
- Excel/CSV 交易文件预检、批量导入、重复文件防重和未知股票自动入池；
- FIFO 批次和移动平均成本；
- 已实现、未实现、今日及累计盈亏；
- 免费优先的 Yahoo 日行情 Provider；
- 手动收盘价补录；
- 每日持仓快照；
- 综合可靠度评分和 85 分发布闸门；
- 应用内、macOS 桌面和 SMTP 邮件通知框架；
- OpenAI-compatible 云端 LLM 接口；
- 收盘后单股和股票池基础复盘；
- 定时行情更新和日终任务；
- SEC 股票代码/CIK 映射、10-K/10-Q/8-K 文件同步；
- SEC Company Facts 核心 US-GAAP 指标标准化；
- 年度、季度财务趋势和 SEC 原文追溯；
- 基于 SEC 年度及中期 GAAP 摊薄 EPS 构造 TTM EPS 的静态 PE；
- 带基准日、来源和历史快照的 NTM 预期 EPS 与动态 PE；
- Alpha Vantage 分析师一致预期自动同步、7/30 日 EPS 修订趋势及分析师上调/下调证据；
- 自动选取两家同行业上市龙头、同步同业数据并计算估值/营收增速/毛利率中位数；
- 目标公司相对同业动态 PE 中位数的折价/溢价分析，并明确有效样本数量；
- 1/3/5 年历史静态及动态 PE 分位；历史静态 PE 仅使用价格日之前已提交的 SEC EPS，动态 PE 不使用当前预期回填历史；
- 所有预测、可靠度、通知和复盘的版本化数据表。

## 停止和重启

```bash
npm stop
npm restart
```

服务启动成功后会在 `data/server.pid` 记录进程号。`npm stop` 只会停止由本项目记录的服务，不会按名称批量终止其他 Node 程序。

如果启动时提示端口 `3789` 已被其他程序占用，先运行 `npm stop`。如果仍然占用，可以在 `.env` 中修改：

```dotenv
APP_PORT=3790
```

## 批量录入交易

打开“交易流水”，在右侧“批量录入交易”区域下载 Excel 模板。系统也接受同样表头的 CSV 文件，单个文件最大 5 MB、最多 1000 笔交易。

模板列依次为：`交易日期`、`股票代码`、`股票名称`、`交易方向`、`股数`、`成交价`、`交易费用`、`备注`。交易日期使用 `YYYY-MM-DD`；方向填写 `BUY`/`SELL` 或“买入”/“卖出”；股数必须大于 0；成交价和交易费用不能为负，其中费用留空按 0 处理。

上传后软件只做预检，不会立即写入。预检会检查表头、日期、数值、重复行和历史持仓是否足够卖出。全部通过并点击“确认批量导入”后才会原子写入；文件内未在股票池中的代码会同时新增到股票池。已经成功导入过的相同文件不能重复导入。

## 云端 LLM

复制 `.env.example` 为 `.env` 后配置：

```dotenv
LLM_ENABLED=true
LLM_BASE_URL=https://api.openai.com/v1
LLM_API_KEY=你的密钥
LLM_MODEL=你选择的模型名称
```

软件使用 OpenAI-compatible `/chat/completions` 接口。密钥不会通过界面返回，也不应提交到版本管理。

## SEC EDGAR 联系信息

SEC 要求自动访问者通过 HTTP `User-Agent` 标识身份并提供真实联系邮箱。在项目根目录的 `.env` 中配置：

```dotenv
SEC_USER_AGENT=你的姓名 your-email@example.com
SEC_REQUESTS_PER_SECOND=5
```

例如：

```dotenv
SEC_USER_AGENT=Zhang San zhangsan@example.com
```

`SEC_USER_AGENT` 不是 SEC 账户或 API Key，只是请求身份标识。软件界面只显示是否已配置，不会回显姓名和邮箱。SEC Provider 会拒绝缺少有效联系邮箱的自动请求，并将请求速率限制在每秒 1–10 次范围内。

配置完成并重启软件后：

1. 将股票加入股票池；
2. 打开“财报分析”；
3. 选择股票并点击“同步 SEC 数据”；
4. 查看最新核心指标、年度/季度趋势以及 10-K、10-Q、8-K 原文。

当前标准化范围以 `us-gaap` 核心概念为主，包括营业收入、毛利润、营业利润、净利润、摊薄 EPS、经营现金流、资本开支、总资产、总负债、股东权益、现金及摊薄加权股数。公司自定义 XBRL 扩展标签和 IFRS 指标将在后续版本补充。

## Alpha Vantage 盈利预期

在项目根目录的 `.env` 中配置免费 Alpha Vantage Key：

```dotenv
ALPHA_VANTAGE_API_KEY=你的Key
```

日终任务会为股票池标的及两家自动对标公司同步分析师一致预期，同一股票同一交易日只请求一次，避免浪费免费额度。动态 PE 优先使用未来四个连续财季平均 EPS 之和；若 Provider 只给出不足四个未来财季，则按距离最近财年末的天数滚动加权未来两个财年的平均 EPS；若下一财年几乎完整覆盖未来十二个月，则允许以该财年预期近似 NTM，并明确标记为近似值。系统保存基准日、上下限、最低分析师覆盖数、预期修订和逐期组成，且不会在数据不足时发布动态 PE。

## 估值与竞争对手

打开“估值与同业”后，系统会根据股票代码、SEC SIC 行业和股票池行业信息，自动选取两家同行业上市龙头作为对标公司，不需要手工维护竞争对手。对标公司只作为研究标的保存，不会加入持仓股票池；点击“自动匹配并同步同业”会同时获取目标公司和两家对标公司的免费 Yahoo 日行情及 SEC 财务数据。页面会显示匹配方式、规则版本和可追溯的行业依据；无法可靠识别行业时会明确提示，不会随意猜测。

静态 PE 使用“最新收盘价 ÷ TTM GAAP 摊薄 EPS”。最新财年结束后直接使用 SEC 最新年度 EPS；财年后已有 10-Q 时，使用“最新年度 EPS + 本期 YTD EPS − 上年同期 YTD EPS”滚动到最近十二个月；只有缺少年度数据时才回退到四个连续季度之和。缺少可比期间或 TTM EPS 不为正时，系统明确显示原因且不发布无意义数值。

动态 PE 使用“最新收盘价 ÷ NTM 预期 EPS”。系统自动同步 Alpha Vantage 分析师一致预期并保留每日历史快照；手工录入仅作为 Provider 无覆盖或需要人工覆盖时的备用口径。Alpha Vantage 预期与 SEC GAAP 历史 EPS 可能采用不同调整口径，页面会保留来源和计算方法，不能把静态 PE 与动态 PE 的差异全部解释为盈利增长。

同业中位数只使用两家自动对标公司中的有效值，不包含目标公司；页面同时展示年度营收同比和毛利率，缺失或无意义的数据不会进入中位数计算。

## 邮件通知

当前内置 SMTP 客户端支持 TLS 直连，通常使用 465 端口：

```dotenv
EMAIL_NOTIFICATIONS_ENABLED=true
SMTP_HOST=smtp.example.com
SMTP_PORT=465
SMTP_SECURE=true
SMTP_USERNAME=用户名
SMTP_PASSWORD=应用专用密码
EMAIL_FROM=发件地址
EMAIL_TO=收件地址
```

建议使用邮件服务提供的应用专用密码，不要使用账户主密码。

## 行情数据说明

默认 Provider 使用无需 API Key 的 Yahoo Chart 接口，适合作为个人测试和早期日终数据源，但不保证长期稳定、完整或实时。系统同时支持手动补录，并已将业务逻辑与 Provider 解耦，后续可以更换为正式行情供应商。

## 日终任务

默认按美东时间 18:15 检查并执行日终任务，包含：

1. 更新启用股票行情；
2. 同步启用股票的 SEC 申报与核心财务事实；
3. 计算并保存每日持仓收益；
4. 生成基础单股复盘；
5. 生成股票池总复盘；
6. 发送完成通知。

如果 `SEC_USER_AGENT` 尚未配置，日终任务会跳过 SEC 同步而不会阻断行情、收益和复盘流程。单只股票同步失败也只记录该股票错误，不会终止整个股票池任务。

也可以在界面点击“执行日终任务”手动运行。
